## 是什么

REA（Reverse Engineer Anything）是一套给编码 agent 用的逆向工程工具集，定位是"从应用行为到原生二进制"全链路的逆向分析。它以 npm 包 `rea-agents` 发布（撰写时为 v4.0.1），从包关键字看同时提供 MCP server、CLI 和 agent skills 三种接入形态，可以把逆向/反汇编/反编译能力挂进 Claude Code、Codex 等 agent 工作流。README 提供英/中/日/韩等多语言版本，面向国际社区。

## 解决什么问题

传统逆向工程门槛极高：需要 IDA/Ghidra 等工具经验、汇编读写能力、协议与文件格式分析功底，普通业务工程师基本无缘。而"搞清楚一个 App 的某个功能是怎么实现的"、"这个无源码依赖到底在干什么"又是真实高频的需求。REA 把逆向任务交给 agent：用自然语言描述目标，由 agent 驱动观测行为、静态分析、下探二进制，把"专家专属"的流程变成对话式的探索。

## 适用场景

- **学习与研究**：理解优秀应用/闭源库的实现思路，作为架构与算法的参考。
- **排查与兼容**：定位无源码第三方依赖（SDK、驱动、遗留二进制）的行为，辅助迁移或兼容性修复。
- **安全分析**：在授权范围内做漏洞研究与恶意样本分析（静态分析、反汇编是其 npm 关键字中明确列出的能力）。
- **协议与格式逆向**：搞清私有文件格式或网络协议，用于互操作或数据迁移。

## 潜在问题与风险

- **法律与合规是第一道门槛**：逆向专有软件普遍违反 EULA，各法域边界不同（如 DMCA、欧盟软件指令、中国著作权法对反向工程的规定差异很大）。商业场景使用前必须过法务，这份风险 agent 本身不会替你把关。
- **双重用途属性**：反汇编/反编译能力同样适用于破解与保护绕过，使用应严格限定在自己拥有或获授权的目标上。
- **结论可信度**：agent 逆向结论可能存在幻觉，关键判断必须人工复核二进制证据；不能直接当结论用。
- **成熟度**：仓库 2026-04 创建，尚年轻（快照时 6.9k Star、67 个 open issue）；"anything" 是宣传口径，实际覆盖深度取决于目标复杂度与 agent 能力上限。
- **许可与合规面本身健康**：项目 MIT 许可、更新活跃（快照当日仍有推送），作为工具使用无许可风险。
