## 是什么

TypeScript 教育领域知名作者 Matt Pocock 开源的个人 agent skills 合集——"我每天用来做真实工程（而非 vibe coding）的技能"。定位是与 GSD、BMAD、Spec-Kit 这类全流程框架相对的另一极：每个 skill 小颗粒、易改、可组合，兼容任意模型。配套站点 aihero.dev/skills。MIT 许可，2026-02 创建，八个月 27.7 万 Star、2.3 万 fork，是这个赛道的现象级项目。

## 解决什么问题

现有 agent 工作流框架的共同模式是"接管整个过程"：你交出控制权，换来开箱即用的流程。代价是流程出错时难以定位和干预——框架本身成了新的黑盒。skills 的主张是反过来：工程师保留流程控制权，把可复用的工程动作（而非整个流程）封装成小 skill，按需组合。27.7 万 Star 的传播速度说明"框架疲劳"是普遍情绪，这个平衡点击中了痛点。

## 适用场景

- **想要结构化但不想要框架的团队**：给 Claude Code/Codex 等 agent 加工程约束，又不被整套流程绑架。
- **编写自有 skills 的参考**：作为"小、可组合"设计理念的成熟样本，比从头摸索省力。
- **评估工作流方法论**：想比较"全托管框架 vs 组合式 skills"两条路线时，这是后者的代表样本。
